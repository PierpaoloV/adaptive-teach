# Roadmap model

`ROADMAP.md` keeps the full destination visible and the current work precise.

## Levels

1. Mission: observable end result.
2. Milestones: outcomes and exit criteria, each no longer than three months.
3. Modules: coherent capability groups inside the current milestone.
4. Lessons: one observable capability each, detailed only for the current
   milestone.

## Planning rules

- Treat prerequisite edges as hypotheses. Record source-backed, inferred, and
  learner-specific edges distinctly.
- Plan the complete route at low resolution. Detail only the current milestone.
- Replan the next milestone from the completed milestone's evidence.
- Preserve completed IDs and evidence when scope changes.
- Distinguish active hours from calendar duration.
- Estimate optimistic, probable, and pessimistic workload with confidence and
  stated assumptions.

Choose the next capability from the ready frontier by mission relevance,
prerequisite readiness, concepts unlocked, likely misconception risk, and fit
within available session time.
