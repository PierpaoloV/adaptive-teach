# Computing domain guide

Assess separate capabilities for reading, explaining, modifying, debugging, and
creating code or configurations. Prefer authentic repositories and executable
tasks over vocabulary recall.

Use independent automated checks wherever possible: unit or integration tests,
type checking, linters, reproducible commands, sample inputs, and observable
artifacts. A passing test is evidence of behavior, not automatically of
understanding; pair it with reasoning or teach-back when the mission requires
selection and explanation.

Vary problem wording and data. Test when the learner chooses a technique and
when they reject it, not only whether they can reproduce a demonstrated pattern.
